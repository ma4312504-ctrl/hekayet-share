# حكاية شارع — موقع أخبار المنيا والقرى والمراكز

## الملفات
- `index.html`: واجهة الموقع.
- `style.css`: الألوان والتنسيق (كحلي وأبيض).
- `app.js`: التفاعل والأخبار التجريبية.
- `supabase_schema.sql`: نقطة بداية لقاعدة بيانات Supabase مع سياسات RLS.
- `README_AR.md`: تعليمات النشر.

## تجربة النسخة
افتح `index.html` في متصفح حديث. لوحة المحررين التجريبية: `admin` / `admin123`.
لا تستخدم هذه البيانات على موقع عام. النسخة الحالية تحفظ البيانات محليًا في المتصفح، وحساباتها ليست آمنة للنشر العام.

## النشر المجاني على Cloudflare Pages
1. فك ضغط الملف على جهازك.
2. افتح https://dash.cloudflare.com/ وسجّل الدخول/أنشئ حسابًا.
3. ادخل Workers & Pages ثم Create application ثم Pages ثم Direct Upload / Drag and drop.
4. ارفع الملفات من المجلد بحيث يكون `index.html` في جذر الملفات، ثم Deploy site.
5. سيظهر رابط عام على نطاق `pages.dev`. يمكن إرسال الرابط للناس. النشر لا يضمن الظهور الفوري في Google.

الدليل الرسمي: https://developers.cloudflare.com/pages/get-started/direct-upload/

## ربط قاعدة بيانات آمنة عبر Supabase
1. أنشئ مشروعًا جديدًا على https://supabase.com/ (الخطة المجانية تخضع لحدود الاستخدام والتغييرات).
2. افتح SQL Editor، والصق محتوى `supabase_schema.sql` وشغّله.
3. من Authentication أنشئ حسابات المحررين بنفسك. لا تفتح التسجيل العام للمحررين.
4. أضف صفًا لكل مستخدم موثوق إلى `public.user_profiles` باستخدام لوحة SQL؛ استخدم role=admin للمدير وrole=editor للمحرر.
5. من Project Settings خذ Project URL وpublishable/anon key فقط إلى الواجهة عند ربط SDK. لا تضع `service_role` key في ملفات المتصفح أبدًا.
6. يجب تعديل `app.js` لقراءة الأخبار المنشورة من Supabase، وإرسال الإضافة/التعديل/الحذف بعد تسجيل دخول Supabase Auth. ملف SQL وحده لا يربط الواجهة تلقائيًا.
7. اختبر أن الزائر غير المسجل لا يستطيع إضافة/تعديل/حذف، وأن الأخبار غير المنشورة لا تظهر للعامة.

## ملاحظات مهمة
- `supabase_schema.sql` بداية عملية، وليس بديلًا عن مراجعة واختبار الأمان قبل الاستخدام العام.
- النسخة الحالية واجهة أولية فقط؛ الأخبار التجريبية يجب استبدالها بأخبار حقيقية موثقة.
- احصل على حقوق الصور والفيديوهات، وتحقق من الأخبار ومصادرها قبل النشر.
- اسم الموقع والشعار والألوان قابلة للتغيير من الكود. بعض الإعدادات التجريبية داخل لوحة التحكم محلية فقط.
